# Pokku Desktop downloads

Download hosting for **Pokku Desktop**, the Windows companion to Pokku for Android, by Waxoo Studio
(the trade name of Muhammad Wasif Younus). This repository contains release files only, no source code.

- Download page: https://waxoostudio.com/apps/pokku/download
- Privacy policy: https://waxoostudio.com/apps/pokku/privacy
- Support: support@waxoostudio.com

Windows preview downloads are unpackaged and not Authenticode-signed. They are not Microsoft Store releases.
Check each file's SHA-256 against the value on the download page before running it.
